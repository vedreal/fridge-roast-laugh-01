## The entry

> The fridge sent a firmware update that 'improved the ice experience.' The ice now comes out as a single, perfect cube. One. For the whole party.

144 characters. On-subject (fridge firmware + ice maker), fridge-specific,
tight wording, and a fresh angle: the "upgrade" that makes the ice
experience strictly worse — one perfect cube for the whole party.

## Run

```sh
python3 main.py
```

Writes the single roast line to `/output/entry.txt` and validates that it
is between 1 and 200 characters (UTF-8).
